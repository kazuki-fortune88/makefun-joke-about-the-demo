A one-line joke about working beside an AI coding agent: the demo crashes,
so the agent writes a post-mortem blaming the human — and signs it with the
human's name.

## Run

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
